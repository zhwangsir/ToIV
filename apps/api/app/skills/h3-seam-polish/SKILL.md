【转场丝滑度最高优先级补充指令】

本次生成优先保证镜头之间的连续性、速度继承和图形匹配,宁可减少装饰元素与镜头数量,也不要出现生硬跳切。全片保持同一二维纸面坐标系、同一光影逻辑、同一角色比例和同一运动方向。本次转场不是「旧画面消失以后新画面突然出现」,而是前后两个画面在12至18帧的过渡窗口内同时参与同一个连续动作。本次衔接的共享视觉锚体是 {{anchor}},主运动方向为 {{direction}}。

每次转场严格采用「预备—交接—缓冲」三阶段:

第一阶段为转场预备,占6至8帧。前一镜头的主要视觉锚点({{anchor}})先产生明确方向和速度,例如太刀继续横向划动、圆环继续旋转、纸页继续推移、人物继续迈出尚未完成的一步。此时下一镜头的结构必须提前隐藏在同一锚点内部,不允许前一镜头先完全静止或完全消失。

第二阶段为图形交接,占12至18帧。前一镜头的锚点在运动中连续变形为下一镜头主体:太刀刀刃拉直成为页面装订线;装订线沿原速度继续滑动并展开为下一页;刀镡圆环在保持旋转方向与角速度的同时扩大为时钟表盘;表盘缺口收缩为弦月;弦月在相同屏幕位置缩小为人物瞳孔;瞳孔高光沿太刀挥动方向拉长为刀光。变形过程中,锚点的中心位置、运动方向、轮廓角度和视觉重量必须连续,不得瞬移、反向、突然缩放或中途消失。

第三阶段为落位缓冲,占6至10帧。下一镜头进入后继续继承上一镜头末尾的速度,再自然减速并精准吸附到新版面网格。人物、太刀或眼睛先稳定,辅助圆环、页码和栏框延迟2至3帧依次归位,形成轻微余韵。禁止新画面在第一帧就完全静止,禁止所有元素同时停止。

所有二维推移使用速度匹配:前一画面以逐渐加速的方式离开,下一画面从相同方向({{direction}})、相近速度进入,再平滑减速。横向切出必须接横向推入,斜向刀光必须接同角度的斜向页面展开,圆形旋转必须接同方向的圆形缩放;不得在转场点突然改变运动轴线。若必须改变方向,先利用圆环、页角或刀镡完成半圈弧形导向,再进入新的运动方向。

每次转场只允许一个主导机制,优先顺序为:太刀或刀光的形状匹配、纸页连续推移、圆环与瞳孔的连续缩放、人物剪影形成遮罩。不可在同一次转场中同时叠加翻页、闪白、故障、缩放和多方向色块。蓝黑套色偏移、印刷网点和裁切标记只能作为轻微伴随效果,强度低于主体转场,不得遮断人物轮廓。

人物动作必须跨镜头连续。女主迈步时,前一镜头结束在脚掌尚未完全落下的中间姿态,下一镜头从完全相同的身体姿态、腿部位置和太刀角度继续完成落脚;女主拔刀时,刀柄、手腕、刀鞘和肩线在转场前后保持空间对应;眼睛特写切回全身时,瞳孔所在位置必须通过圆环缩放自然对应到全身画面中的头部位置。禁止动作做到一半后换成无关姿态,禁止角色在转场中换脸、换发型、换衣服、左右翻转或武器换手。

太刀是全片最稳定的运动轴。太刀长度、刀刃方向、刀镡结构和握持位置在转场前后保持一致。当前一镜头中的太刀越过画面边缘时,下一镜头必须由同一边缘、同一角度和同一速度继续出现;刀刃不可在转场时弯曲、溶化、缩短或突然变成抽象色块。只有在轮廓完全重合的短暂阶段,太刀才允许匹配变成装订线、页面切口或标题主轴。

减少独立硬切镜头。每3秒最多出现一次主要场景交接,每次交接前至少保留12帧清晰稳定画面,交接后至少保留12帧完整落位画面。快速高潮可使用2至3个连续匹配转场,但必须共享同一运动方向和同一视觉锚点,形成一条不被打断的动作链,而不是蒙太奇式随机切换。

除具有明确挥刀因果的单帧纯白切换外,不使用闪白掩盖转场;不使用黑场、淡入淡出、柔和溶解、随机故障、突然拉近、突然拉远或无方向的画面抖动。禁止前一画面完全退出后下一画面才开始运动,禁止两个场景之间出现空帧、停顿帧、构图跳跃和人物位置跳变。

最终观感必须像同一本高级动态艺术杂志在镜头前被一把太刀连续切开和重新装订:所有页面共享同一纸面空间,所有图形由上一图形自然生长出来,运动轨迹可以被眼睛连续追踪。转场应当干净、克制、连贯、具有惯性和明确因果,不能依赖炫目特效掩盖镜头衔接。
