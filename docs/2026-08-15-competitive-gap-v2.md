## 〇、执行摘要

**行业格局三大判断(2026-08)**:

1. **头部已进入「Omni 统一架构」竞赛**:gemini-omni(Google T2V 榜一)、Seedance 2.x、MiniMax H3、可灵 3.0 Omni、Wan3.0 全部转向「理解+生成一体、多模态参考、原生音频」——单点 T2V 时代结束。
2. **Agent 工程化收敛为确定性范式**:Mavis 的 Team Engine 状态机、Skywork 的 Dynamic Workflows 断点续跑+专项复核、Flowith 的计划可编辑——**ToIV R3.1/R3.2 的 LangGraph+Verifier+PostgresSaver 路线被头部全部背书**,方向无错。
3. **价格战开打,自托管成本曲线天然受益**:H3 API 0.8 元/秒(官价 1/3 清场)、Wan3.0 API 0.3 元/秒、Seedance 2.5 补贴价 0.21 元/秒——而 ToIV 自有集群边际成本≈0,且 **I2V 全球第一的引擎(H3,1489 Elo)就在我们自己手里**。

**ToIV 真实位置**:**「引擎与工程已是第一梯队,前台体验与生态仍是第二梯队」**。
- 已兑现:R1(实体注册表/指代闸门/质量门决策层)、R2(VACE+Animate 多参考引擎+参考资产库)、R3(Agent Team 统一入口+LangGraph 断点续跑+任务卡片+双确认门)、Film Atelier v6.1 全站 UI、诛仙 5min 竖屏短剧全链路实证(25 镜+台词口型+4K 交付)。
- 真差距:画布编辑器、Skills 广场(R4 未动)、评测闭环 L2/L3(R5 未动)、工作流商品化、视频编辑产品化、文档直喂入口、短剧工业化资产 UI、商业化计费体系。

**路线总纲**:R4 技能广场+模板化(飞轮启动)→ R5 评测闭环+画布编辑器(交付质量)→ R6 工作流商品化+短剧工业化+视频编辑(B 端能力)→ R7 商业化(计费/激励/桌面叙事)。**全部自托管栈,无新增云依赖。**

### 2.3 用户视角三大「未达预期」根因(对应用户痛感)

1. **「生成完就结束」 vs 竞品「生成才刚开始」**:Lovart/即梦/rhTV 都把首版产物当草稿——改字、扩图、局部重绘、Move Object、逐帧编辑。ToIV 产物只能看和下,**迭代必须重抽卡**,体验断档。→ 画布编辑器(R5)是第一优先级体验工程。
2. **「每次从零开始」 vs 竞品「资产越用越厚」**:Liblib 模型卡、Lovart Brand Kit、可灵元素绑定、RHSTORY 资产库——竞品的核心留存是资产复利。ToIV 角色资产库/参考资产库已建但**前置引导弱**,Skills 广场未启动,模板复用无入口。→ R4+R6 补资产飞轮。
3. **「质量靠运气」 vs 竞品「质量有门禁」**:Mavis Verifier 状态机、Skywork 专项复核、Lovart 消灭抽卡——头部都在把验收做成机制而非运气。ToIV R3.2 的 Director Gate 还是 LLM 自觉,诛仙靠人工 QA 逮出 2 镜幻视(证明有效但不可规模化)。→ R5 评测闭环把诛仙人工 QA 自动化。
