## 一、页面可直接测试的功能

### 1. 反推提示词(图/视频/音频 → 提示词)

**位置**:任意生成表单的 PromptBar「反推」按钮 → 上传文件。

| 测试项 | 操作 | 预期 |
|---|---|---|
| 图片反推 | 上传一张照片(风景/人物/产品图均可) | 3-5s 出一段英文自然语言长描述 + 负面词,描述应覆盖主体/场景/光线/构图/风格,可直接回填生成 |
| 视频反推 | 上传一段 ≤50MB 的 mp4 | 6-10s 出六段式叙事提示词(运镜→主体→动作→场景→光线→风格),动作描述带时序 |
| 音频反推(人声) | 上传一段有人说话的 wav/mp3 | 1-3s 出转写文本 + 情绪(如 HAPPY)+ 语种 + 事件标注 |
| 音频反推(音乐)⭐ 新 | 上传一段**纯音乐/带 BGM 的音频** | 5-10s,在人声描述后追加「背景音乐: 曲风/乐器/节奏/情绪的英文描述」;纯音乐则直接以音乐描述为主体 |
| R18 图片反推 | R18 上下文(NSFW 模块)里上传成人向图片 | 走 JoyCaption 专线,**不拒答**,输出直白画面描述(不再出现 Qwen3-VL 的回避/拒答) |

**异常排查**:若图像/视频反推 502,先查 studio04(`ssh dgmt-studio04@192.168.71.113 'curl -s localhost:9303/v1/models'`);若音乐部分缺失但人声正常,属增强链降级(查 spark01 omni 容器)。

## 三、建议的验收顺序

1. 先传一张图 → 反推 → 用反推出的提示词直接文生图,看还原度
2. 传一段短视频 → 反推 → 检查六段式叙事是否准确
3. 传一段带 BGM 的配音音频 → 反推 → 确认「人声 + 背景音乐」两段描述都有
4. R18 上下文传一张成人向图 → 反推 → 确认不拒答
5. R18 上下文随意聊几句 → 确认 NSFW 文本正常
6. 连发 3-5 张图 → 确认生成链路无回归

任何一步异常,把「操作 + 文件类型 + 报错/耗时」发我即可定位。
