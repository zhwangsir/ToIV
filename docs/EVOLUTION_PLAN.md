# ToIV 进化计划（2026-09-14 用户批准自主执行）

> **总目标（90 天）**：把 ToIV 从「可用率 ~90% 的 550 应用市场」进化成「对话即可制片」的漫剧生产系统。
> **三条硬指标**：①市场可用率 ≥97% 且新导入应用自动达链 ②剧本→成片全程无节点图、单镜头可预览 ≤2 分钟 ③同一角色 ≥10 镜头脸部/服装无漂移。
> **执行顺序**：Phase 0（进行中）→ 1 → 2 → 3，Phase 4 穿插；每阶段结束交用户验收。

## Phase 0 — 上线收口（进行中，本轮冲刺）
- [ ] wave22（70 app 耐心复测）→ 部署积压修复（调度对称 bug/CLIPVision+WanVideo 探测/fresca 回填）→ wave23 收尾波（含 1880220673 换带脸 fixture）
- [ ] fl2va+turbo LoRA mat1/mat2 对照实验（去 LoRA 提交定位真因）
- [ ] 终局 census（目标 ≥90%）+ whitepaper 豁免清单终版
- [ ] 引擎真跑冒烟（35 引擎抽样）+ 18 个 builtin 封面真出图
- [ ] api/web/MP 全量测试绿 + 决算报告交用户测试
- 验收：用户开始测试，P0 级问题 ≤2 个

## Phase 1 — 应用自愈闭环（~2 周，最高优先）
把「导入→失败→人肉归因→写规则→复测」循环自动化。
- [ ] **失败归因结构化**：tracker/node_errors/白皮书分类法 → 归因表（缺节点/缺模型/校验/运行时/资源/数据），每类挂修复器接口
- [ ] **修复器栈**：现有 30+ normalizer 迁移为「规则库」（数据驱动，热加载）；确定性修复（命名 remap/默认回填/剪死链）全部规则化
- [ ] **LLM 修复器**：确定性修复不了的，DSv4 读失败图+目标实例 object_info → 提议图补丁 → 沙箱 build_graph 校验 → 试提交 → 通过则沉淀为规则（人审队列兜底）
- [ ] **导入即测**：新应用入库自动跑 L2 烟测（runner 产品化），可用率评分落库并透出市场
- [ ] **P2 知识图谱一期**：节点/包/模型/应用四类实体+关系入图（自愈推理的地基；REBEL/图谱查询服务化）
- 验收：新导入 20 个 RH 应用，自动可达率 ≥80%（当前基线 ~60%）；市场页展示可用率评分

## Phase 2 — 漫剧制片线 MVP（~3 周，与 Phase 1 并行启动）
底稿：comfyui平台优化提示词.md（P0-2 角色卡 / P1-3 分镜流水线 / P2-5 成片）。零件全部在 fleet 常驻，纯集成。
- [ ] **角色卡系统**：10 字段卡（基本信息/视觉锚点/服饰/配色/三视图/表情）+ 标准设定图一键导出（三视图+表情拼图）+ 锚点提示词自动注入分镜
- [ ] **一致性分级**：提示词+种子锁（L0）→ PuLID/IPAdapter+ClipVision（L1）→ Qwen-Image-Edit 迭代（L2）→ 主角 LoRA（L3，接 trainer）→ 换脸/对口型兜底（L4）
- [ ] **分镜流水线**：剧本/小说 → DSv4 输出强制 JSON 分镜（附录 B Schema）→ 批量生图 → 抽卡确认 → 首尾帧图生视频 → 片段箱
- [ ] **成片合成**：FFmpeg 合成 + 音轨混音（音频编排已有）+ SRT 软/硬挂（ASR→SRT 已有）+ 抖音/B站规格预设
- 验收：一个 10 镜头样片从剧本到成片 ≤半天（含人工抽卡），角色跨镜头无漂移

## Phase 3 — Agent 导演（~2 周，接 Phase 2）
- [ ] 分镜 JSON 作为 agent 规划格式；agent 工具链：选应用/提交/追踪/验收（video scorer 当眼睛）
- [ ] 对话式制片入口：「把这段小说做成 30 秒短片」→ 计划 → 执行 → 交付（用户可中途改分镜）
- 验收：3 个真实剧本案例全程对话完成，无节点图接触

## Phase 4 — 支撑面（穿插）
- [ ] **项目/资产层**：项目为一等实体（角色/风格/种子/参考媒体跨会话复用）
- [ ] **P3 万能管理台**：fleet 治理驾驶舱（worker/队列/成本/可用率/修复队列）
- [ ] **小程序定位**：审片/管理/发布（不做创作端）
- [ ] **video scorer 转正**：阈值标定 + 全量灰度解除

## 明确不做（本轮）
- push（待用户拍板+清凭据）；开放生态/第三方上架；算力商业化计费；移动端创作。

## 风险与依赖
- DSv4 修复器质量依赖知识图谱覆盖 → Phase 1 内两件事互锁
- 漫剧线强依赖 fl2va/H3 族稳定性（当前 mat1/mat2 残差）→ Phase 0 对照实验必须闭环
- 90 天排期假设算力 fleet 无缩编；若 DRT/Spark 等决策变化需重排
