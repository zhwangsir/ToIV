## 1. 总纲

- **目标（北极星）**：一个入口、一次登录、一个项目空间；剧本到成片不出壳；人与 Agent 操作同一份数据。
- **非目标（冻结，防蔓延）**：RH 市场扩容（冻结 83）、小程序送审、社区/UGC、c_hybrid 翻案、多租户、计费体系。
- **总成功判据（P4 末验收）**：
  1. 经典 web 仅剩 login/官网静态，生产流量 100% 走 canvas 壳；
  2. 新剧全流程（创建→剧本→资产→分镜→镜头→汇编→导出）零外跳、零外部工具；
  3. 中断恢复演练（kill -9 + 重启）100% 续跑；
  4. 桌面（Wails）与 Web 同版本号一次构建产出。
