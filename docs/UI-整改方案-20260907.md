## 五、纪律红线（踩过的坑，别再踩）

- **deploy.sh 不重建前端**：部署前必须本地干净构建，部署后核对 core 上 BUILD_ID 与本地一致
- **styled-jsx 作用域**：多组件文件必须 `<style jsx global>`+前缀，否则样式静默失效且测试全绿
- **测试即契约**：tests/ 里大量断言钉住版型/令牌/文案，改样式先跑测试，断言过时更新断言而非绕过
- **rh-* 播种是代码即正典**：app_seed.py 覆盖更新内置应用，手改 DB 会被重播种覆盖（cover_url 例外，seed 不触碰）
- **后端批次任务是进程内单飞**：deploy 重启会打断封面生成这类批任务（已发生过一次），重跑即可（幂等）
- **文档纪律**：完成后写 TEST_LOG 条目 + STATE.json + commit + 双推（origin=Gitee 主，github 镜像）
