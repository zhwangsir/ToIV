# ToIV LibTV 式工作台大重构设计文档(2026-08-16)

> 依据:9 个开源短剧管线 + 10 家商业平台 UI 形态调研(2026-08-16 四路实机,来源见附录)
> 目标:把 ToIV 创作侧从「纵向长表单」重构为「LibTV/RHSTORY 式专业工作台」
> 范围:一期 = 短剧工作台(drama studio)全重构 + 首页 Agent 对话框 C 位;二期 = 画布/Skills(R4 衔接)

## 〇、形态定义(调研收敛)

**「LibTV 式工作台」= 以项目为容器、以「剧本→资产→分镜→短片」四步为骨架的专业工作台**:入口是项目,中央是阶段工作区,资产(角色/场景/道具)是一等公民并被镜头引用,每个阶段有确认门,镜头级状态与局部重跑可视化,播放器与镜头胶片条就近于生成上下文,人与 Agent 操作同一份项目数据。

关键参照实证:
- **RHSTORY 四步进器 + 双确认门**(剧本创作→美术设定→分镜设计→短片生成;「确认剧本」「确认分镜,进入短片制作」大按钮)——确认前只做零算力产物(文本/故事板图),确认后才烧视频算力
- **分镜用表格不用卡片流**(镜头号|资产缩略|分时段画面描述|故事板图|状态|时长|操作)——30+ 镜可扫读;卡片流留给作品库
- **底部镜头胶片条 + 就近播放器**(缩略图+状态色,n/N 已完成·总时长,连续播放/保存成片)
- **资产一等公民 + @引用**(角色卡=三视图/多角度/色卡;镜头描述 @角色 高亮注入;LibTV AutoLink 按名称+特征自动匹配)
- **Jellyfish 候选确认筐 + readiness 门控**(AI 抽取资产先入候选筐,接受/忽略/关联;镜头「准备中/已备好/生成中」三态分离)
- **wind-comic 镜头情绪标签+beat note+stale 检测+诚实降级徽章**;**Mavis 任务卡状态视觉**(Worker 蓝圈/Verifier 黄帽);**堆友分层编辑**(交付可编辑文件非死图);**Flowith 计划可编辑 + 级联刷新**;**Nomi 批准门下沉 API 层**
- 深色工作台是 LibTV/RHSTORY/千问创作的共识(长时作业护眼+显影准确);堆友/Liblib 主站浅色消费级——**ToIV 采用「浅色门户 + 暗房工作台」双区**,工作台用新的「暗房」主题(呼应 Film Atelier 暗房隐喻,与既有 5 主题并存于主题切换器)

## 二、短剧工作台详细规格

### 2.0 主题:新增「暗房」工作台主题

- 新主题 `darkroom`(globals.css token 派生):近黑底(#0f0f11 系走 token 不定 hex——用 `color-mix` 自 `--bg-canvas` 派生)、文字 `--text-primary` 反白、单一高亮色(琥珀金,呼应胶片放映机暖光)
- 工作台壳层 `data-theme-zone="darkroom"` 局部覆盖,不进全局主题切换器默认值(用户浅色偏好不动);顶栏提供工作台内「浅/暗」即时切换
- 遵守既有硬约束:零 hex 硬编码走 token、reduced-motion、Lucide 唯一图标库、字重不硬编码

### 2.1 顶栏 + 四步进器(恒显)

- 左:返回 + 项目选择器(项目下拉,含新建);右:进度 `n/N 镜` + 「合成成片」主按钮 + 浅/暗切换
- 步进器:①剧本 ②资产 ③分镜 ④短片;完成步 ✓、当前步墨丸、未来步灰;点击可回退到任意已完成步骤
- **确认门**:剧本页底部「确认剧本 →」、分镜页底部「确认分镜,进入短片制作 →」;确认后写 `project.status`(storyboard→ready 等既有字段),资产/分镜阶段在确认前锁定「生成视频」类按钮(允许做零算力产物:剧本/润色/角色定妆/故事板图)

### 2.2 阶段①:剧本(三栏)

| 栏 | 内容 |
|---|---|
| 左(AI 编剧) | 对话窗:基于当前剧本上下文的改写/润色指令(复用既有 refine L2 + polish 端点);消息流 + 输入框 |
| 中(剧本正文) | 大编辑器(现有 textarea 升级为等宽编辑区);场次标题自动高亮(【动作】【台词】标记);字数统计 |
| 右(分场大纲) | 场次卡片列表(从剧本正则提取场次标题);点击定位;底部「保存剧本」+「确认剧本 →」 |

### 2.3 阶段③:分镜表格(核心形态变更)

**表格列**(每行=一镜,行高 64px,密度对齐专业工具):

| 镜号 | 资产 | 画面描述 | 故事板 | 状态 | 时长 | 操作 |
|---|---|---|---|---|---|---|
| #7 | 角色缩略圆片(可 hover 放大) | 双字段:image_prompt(首帧)/video_prompt(运动)分行截断,点击展开编辑(Script-Weaver 双 prompt 实证) | 故事板图缩略(无图显「生成故事板」按钮) | StatusBadge 复用:queued/running/done/error + wind-comic 诚实降级徽章 | 10.1s | 重生成(换 seed)/编辑/续写/口型 |

- 表格上方工具条:模型选择(现有)+「宫格分镜」+「批量生成(带 dry-run 预估:镜数×单镜时长,Forge-Film plan/run 分离实证)」
- 宫格预览保留为可收叠的侧拉块(现有宫格点击定位逻辑复用)
- 镜头行新增字段:`mood`(情绪标签)+`beat`(节拍注记)——DB 加两列(轻迁移),剧本拆解 prompt 要求输出(wind-comic 实证:节奏在列表视图可读)

### 2.4 阶段④:短片生成

- 左栏(镜头详情,复用检查器):场次/镜头下拉;关联资产三槽(+角色/+场景/+道具);画面描述(分时段:「0-3秒(中景…)」格式化为只读参考);故事板/首帧/参考三槽位;模型+参数条;「生成镜头」按钮带预估(时长/帧数)
- 中央:大播放器(单镜;右上角后处理浮层:超分/反推,按次提示)+「连续播放」模式切换
- **底部胶片条**(恒显于短片阶段):镜头缩略条,状态色(完成=缩略图/生成中=呼吸框/排队=灰/失败=红),当前镜描边高亮,可横滑,点击切换播放器;右端汇总 `n/N 已完成 · 总时长 mm:ss` + 「合成成片」
- 局部重生成:镜头行/胶片条双入口;重生写新版本(旧 video_url 保留进 candidates,复用现有 candidates 机制,不覆盖)

### 2.5 阶段②:资产

- 角色卡片墙:定妆三视图(正/侧/背)切换、描述、引用计数(被几镜引用)、「生成三视图」「设为参考」操作;场景/道具同构(复用现有 DramaAsset/参考资产库 API)
- **候选确认筐**(Jellyfish):拆解/润色后 LLM 抽取的新角色入候选区,操作=接受入库/忽略/关联已有;一期可对既有 characters 列表加 `source: candidate|confirmed` 视觉分区(不动 API)
- 资产卡支持拖入镜头行(后续迭代);一期先做「引用计数 + 一键跳转到引用镜头」

### 2.6 右栏检查器

随选中对象切换:选中镜头→镜头详情(同 2.4 左栏内容,短片阶段时为左栏);选中角色→角色详情;未选中→项目摘要(进度/预计总时长/引擎状态)

### 2.7 Agent 内嵌(衔接 R3.2)

- 右栏可切「Agent」页签:内嵌 agent-runs 任务卡(复用 AgentRunView 卡片组件),对本项目的操作(拆镜/批量生成/合成)以 Agent 任务呈现,人与 Agent 改同一份项目数据
- 一期做只读嵌入+跳转;二期做画布原语(LibTV Agent 同画布)

## 三、组件与文件规划

新增(全部 TypeScript + 独立 CSS 文件,遵守 styled-jsx 清零原则):

```
apps/web/components/drama/
  workbench/
    DramaWorkbench.tsx        # 容器:阶段路由/顶栏/胶片条(短片阶段)/浅暗切换
    WorkbenchShell.tsx        # 壳:顶栏+步进器+三栏布局+右栏检查器插槽
    StageScript.tsx           # 阶段①剧本三栏
    StageAssets.tsx           # 阶段②资产卡片墙+候选筐
    StageShots.tsx            # 阶段③分镜表格+工具条+宫格侧拉
    StageProduce.tsx          # 阶段④播放器+镜头详情+胶片条内容
    ShotTableRow.tsx          # 分镜表格行(双 prompt 展开编辑/操作菜单)
    FilmStrip.tsx             # 底部镜头胶片条(状态色/横滑/汇总)
    Inspector.tsx             # 右栏检查器(镜头/角色/项目三态)
    types.ts                  # 组件契约(Props/Stage 枚举)
apps/web/app/styles/drama-workbench.css   # 暗房主题+工作台布局(新)
```

- 复用:`useDramaProject` 全量数据/动作(不改 API)、StatusBadge、CandidateGrid、宫格定位逻辑、ui/Modal 确认门、Icon(Lucide)
- 旧 `DramaView.tsx` 保留项目列表页(入口页),进入项目后渲染 `DramaWorkbench`;旧纵向详情页 `DramaDetail` 在新工作台稳定后删除(一期并存,feature flag `?wb=1` 灰度)
- DB 轻迁移:`dramashot` 加 `mood`/`beat` 两列(可空字符串,默认 "")
- e2e 锚点保留:`.btn-primary`/`.empty-state` 等既有测试锚点在新组件上等价保留
