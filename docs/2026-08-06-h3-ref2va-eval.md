## 二、评测矩阵与结果(1344×768,124 帧,24fps,20 steps,beta 调度器,seed 42)

| 组 | 参考输入 | 场景指令 | 耗时 | 结果 |
|---|---|---|---|---|
| A1 | 楼道近景背影×1,`match` | 隐式(prompt 描述厨房) | 282s(冷,含 NAS 加载) | ❌ 锁死楼道;门牌幻觉成 "617" |
| A2 | 同 A1,`max` | 同 | 222s(热) | ❌ 同 A1;与 match 档逐帧级相似(同 seed) |
| B1 | 楼道×3(0.5/2.5/4.5s 抽帧),`match` | 同 | 263s | ❌ 锁死楼道;门牌 "602" **正确**,菜篮青菜保真 |
| A3 | 楼道远景×1(`match`)* | **显式**「场景切换到与参考图背景完全不同的新场景」 | 292s | ✅ 成功迁移明亮厨房;⚠️ 出现双角色瑕疵 |
| A4 | **真正面肖像**×1(t2v 生成,`match`) | 显式切换 + **单角色约束** | 283s | ✅ 明亮厨房单角色;藏青衬衫/短发型/年龄段全部匹配 |

*A3 原计划生成正面肖像作参考,因评测脚本 t2v 类名 bug(`MiniMaxH3TextToVideo` → 实际存档为 `MiniMaxH3ImageToVideo`)替换 prompt 失败,实际参考图仍是楼道图;意外成就了「显式指令 + 弱场景占比参考图」场景迁移数据点。A4 修正后完成真肖像组。

**显存峰值(逐卡 MiB)**:各组 GPU0 58,319–63,919 / GPU1 67,619 / GPU2 5,277 / GPU3 57,864——远低于第一轮 I2V 的 97.2G 红线,与生产服务共卡无压力。

## 三、关键结论

1. **身份锁定能力极强**。五组输出中角色的衣着、体型、发型、道具(菜篮/青菜)全程一致;3 参考组连场景文字细节(门牌 "602")都保真,1 参考组则幻觉成 "617"——**多参考显著提升细节准确度**。
2. **参考图即场景锚点**。参考图携带的场景信息会一并锁定:隐式场景指令(prompt 只描述新场景)三组全部锁死在原楼道;**显式「场景切换」指令才能解锁**(A3/A4 均成功迁移厨房)。
3. **prompt 工程要点**:迁移场景必须显式声明「切换到与参考图背景不同的新场景」;单角色镜头建议加「画面中只有一个女人」约束(A3 无约束时输出双角色,A4 加约束后单角色)。
4. **`match` vs `max` 档**:同 seed 下画面逐帧级相似,且 max 未更慢(222s vs 282s,后者实为冷启动);官方标称「max 慢数倍」在 1344×768 单参考规模下未体现。**生产默认 match 即可**。
5. **速度**:热态 222–292s/5s 镜,与 fl2va i2v 热启动(209.9s)同量级;肖像 t2v(56 帧)141s。
6. **音频**:各组产物均含 32kHz 立体声音轨(A4 1.5MB vs A1 768KB,音轨内容丰富度更高);台词清晰度/口型同步未做人工听审(遗留)。

## 四、与 fl2va i2v(首尾帧)路线对比

| 维度 | fl2va i2v(第一轮) | ref2va(本轮) |
|---|---|---|
| 一致性机制 | 首帧像素锚定,逐镜外链(需前镜出图) | 参考图 token 全程锚定,任意镜独立生成 |
| 跨场景 | 天然支持(首帧即新场景) | 需显式场景切换指令 |
| 角色卡复用 | 不可(依赖前镜产物) | **可**(干净肖像任意复用) |
| 多角色 | 未测 | 参考 ≤9 图/3 视频/3 音频,标签化引用(`<Picture N>`) |
| 速度 | 热 210s | 热 222–292s(相当) |

**定位互补而非替代**:i2v 适合剧情连续镜头(首尾帧衔接),ref2va 适合「角色卡 → 任意分镜」的短剧生产模式。

## 五、生产接入建议(对 Studio 模块)

1. **角色卡资产规范**:角色参考图用**干净正面肖像/半身照**(A4 验证可行),避免带场景信息的剧照作角色卡(会锁死场景,A1/A2/B1 教训)。
2. **prompt 模板**:分镜 prompt 前置「场景切换到与参考图背景完全不同的新场景,画面中只有 N 个角色」+ `<Picture N>` 按角色卡顺序引用。
3. **多参考**:主角建议 2–3 张(正面/侧面/半身),细节保真度显著优于单图(门牌号对照实验)。
4. **档位**:默认 `match`;`max` 在本分辨率无收益。
5. **优先级**:ref2va 与 i2v 并列作为 Studio 分镜引擎候选;ref2va 解决角色一致性(原 PuLID-Flux 首帧路线的上位替代——免首帧生成、免像素锚定外链)。
6. **合规**:接入前过 MiniMax H3 Community License 条款。

## 七、D1 参考视频(运镜迁移)补测(2026-08-07)

**设计**:角色卡 `a4_portrait_ref.png` + 参考视频 `a4_portrait_kitchen.mp4`(A4 产物,厨房门口缓慢推近运镜,含声轨,经 `LoadVideo → GetVideoComponents` 同时接入 `ref_videos.ref_video_0` 与 `ref_video_audios.ref_video_audio_0`)。prompt 显式「运镜方式参考 `<Video 1>`……场景切换到与参考画面完全不同的新场景」,目标场景为傍晚露天菜市场,新台词「这青菜怎么卖?」。轻量档:1344×768、56 帧(17×3+5 网格)、6 steps、beta 调度器、seed 42、ref_image_size=match。

**产物**:`d1_cameramove_market.mp4`(482KB,2.33s,32kHz 立体声音轨;workstation `output/r2v/` + NAS 同名目录),耗时 161s(含参考视频 VAE 编码),显存峰值 GPU0 56,399 / GPU1 78,209 MiB。

**结论**:
1. **角色一致** ✅——短发夹银丝、藏青衬衫、面容与角色卡/A4 保持同一人物。
2. **运镜部分迁移** ⚠️——抽帧(0.3/1.2/2.1s)可见缓慢推近轨迹,方向与参考一致;但幅度收敛,且因场景未切换(见下),无法完全排除「推近」只是参考视频画面的延续。
3. **场景切换失败** ❌——prompt 已含显式切换指令(A3/A4 同款),输出仍锁死在参考视频的厨房场景(灶台、锅具、窗光齐全)。**参考视频比参考图更强的场景锚点**:视频参考携带的时序画面信息会整体压过文本场景指令,这是与「参考图 + 显式指令可切换场景」(A3/A4)的关键差异。
4. 参考视频声轨中的台词未串入新台词(新台词按 prompt 生成),`<Video k>` 标签引用机制工作正常。

## 八、E1 参考音频(音色)补测(2026-08-07)

**设计**:角色卡 `a4_portrait_ref.png` + 参考音频 `e1_ref_voice.wav`(macOS `say`「Grandma 中文(中国大陆)」生成的 6.67s 中文台词:「我这辈子啊,就守着这个小厨房,看着孩子们一个个长大,心里头就知足了。」音色为老年女性;经 `LoadAudio` 接入 `ref_audios.ref_audio_0`)。prompt 带**不同内容**新台词「今天菜场的小青菜特别新鲜,晚上给你下面吃」,声明「声音、音色和语气参考 `<Audio 1>`」。同 D1 轻量档(56 帧、6 steps、seed 42)。

**产物**:`e1_voice_clone_kitchen.mp4`(1.2MB,2.33s,32kHz 立体声;workstation `output/r2v/` + NAS),耗时 30s(热态)。画面:厨房场景、角色一致、口型张开说话;⚠️ 画面底部出现幻觉字幕(乱码中文),H3 音画同构模型的已知倾向,生产 prompt 需规避。

**音轨客观分析**(本机 ffmpeg + Python 自相关基频估计;主观听审不可行,以下之外的部分不可定论):

| 指标 | 参考语音 | E1 产出音轨 |
|---|---|---|
| 时长 | 6.67s | 2.33s(全片) |
| 均值响度 | −22.0 dB | −14.5 dB |
| 频谱质心 | 1,052 Hz | 2,698 Hz(含水流/擦拭环境音,宽带噪声上移质心) |
| 频段能量(低<300Hz / 人声300–3400Hz / 高>3400Hz) | −23.2 / −28.4 / −44.2 dB | −16.1 / −19.9 / −30.0 dB(剖面形状一致:低频主导、高频陡降) |
| 基频 F0 中位数(p10–p90) | 108 Hz(82–134) | 200 Hz(112–254) |

**结论**:
1. **音轨存在且含连续人声** ✅——无 >0.3s 静音段,抽帧口型张开,人声段与画面同步。
2. **音色类型相近但未克隆** ⚠️——产出为成年女性声线,与参考同性别、同低寄存器方向(频段剖面形状相似);但 F0 相差近一个八度(200 vs 108 Hz),参考的「老年」音高特征未迁移。台词内容与清晰度无 ASR 验证,不可定论。
3. 单条 2.3s 轻量档样本不足以区分「音色克隆能力弱」与「轻量档/短时长下参考音频权重不足」;如需定论,建议 124 帧 20 steps 档 + 多条参考音频复测。
