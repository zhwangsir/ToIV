## 二、AI 短剧/视频平台深度分析

### 2.1 可灵 AI (Kling AI)

#### 设计理念
- **"一张画布"哲学**：解决传统界面"来回跳转、迷失素材"的痛点
- **电影工业隐喻**：将 AI 视频生成类比为电影后期工作台
- **所见即所得**：节点连线直接表达工作流逻辑，降低认知负担

#### 功能布局（三栏结构）
```
┌─────────────────────────────────────────────────────────────┐
│  [顶部导航栏] Logo | 工作台 | 素材库 | 历史记录 | 用户中心   │
├──────────┬──────────────────────────────────┬───────────────┤
│          │                                  │               │
│ 左侧面板 │       中央无限画布区域            │   右侧面板    │
│          │                                  │               │
│ - 节点库 │  - 节点卡片 (Prompt/模型/参数)    │ - 属性面板    │
│ - 素材库 │  - 连线表示数据流                 │ - 参数调节    │
│ - 预设   │  - 结果预览卡片                   │ - 生成历史    │
│          │  - 迷你地图 (右下角)              │ - 版本对比    │
│          │                                  │               │
└──────────┴──────────────────────────────────┴───────────────┘
```

#### 信息架构特点
- **节点即模块**：每个功能（提示词输入、模型选择、参数调节、结果输出）都是独立节点
- **连线即逻辑**：清晰表达"输入→处理→输出"的数据流关系
- **卡片化结果**：生成结果以浮动卡片形式直接在画布上呈现，无需跳转
- **迷你地图**：右下角小地图提供全局导航，快速定位工作区

#### 视觉风格
- **极简主义**：大量留白，视觉焦点集中在内容
- **深色主题为主**：专业工具定位，减少视觉干扰（注：ToIV 偏好浅色主题，需做适配）
- **卡片微质感**：节点卡片有 subtle 阴影和圆角，层级分明
- **克制动画**：仅在节点添加、连线、生成进度时使用微动效

#### 配色方案（可参考浅色适配）
| 色值 | 用途 |
|------|------|
| `#000000` / `#FFFFFF` | 主色，黑白对比 |
| `#F5F5F7` | 画布背景 |
| `#E8E8ED` | 节点/面板背景 |
| `#007AFF` (蓝) | 主要操作、连线高亮 |
| `#34C759` (绿) | 成功状态、运行中 |
| `#FF9500` (橙) | 警告、排队中 |
| `#FF3B30` (红) | 错误、失败 |
| `#8E8E93` | 次要文字、图标 |

### 2.2 即梦 AI (Jimeng AI)

#### 设计理念
- **创作工具原生**：抛弃聊天对话框范式，采用 Figma/Photoshop 式专业工作台
- **预测式交互**：根据用户操作历史预判下一步，智能推荐功能
- **沉浸无干扰**：创作时 UI 自动隐退，鼠标移动呼出控制

#### 功能布局（类 Figma 结构）
```
┌─────────────────────────────────────────────────────────────┐
│  [顶部应用栏] 首页 | 创作中心 | 智能画布 | 灵感社区 | 我的   │
├──────────┬──────────────────────────────────┬───────────────┤
│          │                                  │               │
│ 左侧工具栏│       中央无限画布               │  右侧属性栏   │
│          │                                  │               │
│ ▢ 选择   │  ┌─────────────────────────┐    │ [选中元素时]  │
│ ✎ 文本   │  │  素材卡片 / 生成结果     │    │ - 参数调整    │
│ 🖼 图片   │  │  可拖拽、缩放、重叠      │    │ - 风格选择    │
│ 🎬 视频   │  │                         │    │ - 导出设置    │
│ 🎵 音频   │  └─────────────────────────┘    │               │
│ 🎨 特效   │                                  │ [无选中时]    │
│          │  [底部时间线/轨道区]              │ - 全局设置    │
│          │  - 片段排列、裁剪、转场            │ - 项目信息    │
│          │                                  │               │
└──────────┴──────────────────────────────────┴───────────────┘
```

#### 信息架构特点
- **五大模块**：首页（推荐/模板）、创作中心、智能画布（核心）、灵感社区、我的
- **无限画布优先**：所有素材、元素、结果都在同一画布上组织，类似设计工具
- **智能推荐层**：非侵入式的功能推荐浮层，不打断创作流
- **社区即灵感**：灵感社区与创作中心无缝衔接，一键复用他人作品

#### 视觉风格
- **轻盈现代**：白色/浅灰为主，清爽通透
- **圆角系统**：8px 小按钮、12px 卡片、20px 大面板，统一圆角语言
- **毛玻璃效果**：悬浮工具栏使用 backdrop-blur，层次感强
- **微动效**：选中态呼吸效果、拖拽时磁吸对齐、生成时的进度水波纹

#### 配色方案
| 色值 | 用途 |
|------|------|
| `#FFFFFF` | 主背景 |
| `#FAFAFA` | 画布背景 |
| `#F5F5F5` | 工具栏/面板背景 |
| `#FE2C55` (抖音红) | 品牌色、主要 CTA |
| `#25F4EE` (抖音青) | 辅助强调色、选中态 |
| `#161823` | 主文字 |
| `#8A8B91` | 次要文字 |
| `#00000014` | 阴影、分隔线 |

### 2.3 Runway Gen-3

#### 设计理念
- **专业后期工作室**：对标 Premiere Pro / DaVinci Resolve，面向专业创作者
- **时间线为王**：视频创作的核心是时间线编辑，其他功能围绕其展开
- **工具集模式**：左侧素材库 + 中间预览 + 右侧参数 + 底部时间线

#### 功能布局（标准专业 NLE 结构）
```
┌─────────────────────────────────────────────────────────────┐
│  [顶部菜单栏] 项目 | 编辑 | 效果 | 导出 | 帮助              │
├──────────┬──────────────────────────────────┬───────────────┤
│          │                                  │               │
│ 左侧素材库│       中央预览窗口               │  右侧参数面板  │
│          │                                  │               │
│ - 项目   │  ┌─────────────────────────┐    │ - Inspector   │
│ - 媒体   │  │                         │    │ - 效果控制    │
│ - 效果   │  │    视频播放预览          │    │ - 颜色校正    │
│ - 标题   │  │                         │    │ - 音频混合    │
│ - 转场   │  └─────────────────────────┘    │               │
│          │                                  │               │
├──────────┴──────────────────────────────────┴───────────────┤
│  [底部时间线区域]                                            │
│  ┌─────────────────────────────────────────────────────┐  │
│  │ 视频轨 V1  [片段1][片段2][片段3]                      │  │
│  │ 视频轨 V2           [叠加层]                          │  │
│  │ 音频轨 A1  [~~~~~~~~~~~~~~~~~~~~]                     │  │
│  │ 音频轨 A2           [音效]                             │  │
│  └─────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

#### 信息架构特点
- **项目制组织**：每个短剧/视频是独立项目，包含所有素材、时间线、设置
- **媒体池概念**：所有上传/生成的素材统一在媒体池管理，可拖拽到时间线
- **检查器模式**：右侧 Inspector 是上下文敏感的，选中什么显示什么参数
- **多轨道编辑**：支持多视频轨、多音频轨，精确到帧的编辑

#### 视觉风格
- **深色专业主题**：#1a1a1a 深灰背景，减少眼部疲劳（长时间编辑）
- **高对比度**：亮白文字配深色背景，关键元素突出
- **精细控制**：滑块、旋钮、时间码等控件精致专业
- **示波器**：可选的波形图/矢量示波器，专业级调色参考

| 色值 | 用途 |
|------|------|

| `#2D2D2D` | 面板背景 |
| `#3D3D3D` | 控件/按钮背景 |
| `#FFFFFF` | 主文字 |
| `#AAAAAA` | 次要文字 |
| `#0066FF` (蓝) | 播放头、选中高亮 |
| `#FF6B35` (橙) | 关键帧标记、录制 |
| `#00D084` (绿) | 渲染成功、状态正常 |

### 2.4 Pika 2.0

#### 设计理念
- **极简快速**："10 秒出片"，降低创作门槛
- **聊天→工作台演进**：从 Discord 机器人演化为网页工作台，保留对话式直觉
- **焦点突出**：生成时整个界面聚焦于结果，其他元素弱化

#### 功能布局（简洁两栏）
```
┌─────────────────────────────────────────────────────────────┐
│  [极简顶栏] Pika | 我的作品 | 探索 | 定价                   │
├──────────────────────────────────┬──────────────────────────┤
│                                  │                          │
│       左侧输入区                 │     右侧结果区           │
│                                  │                          │
│  ┌─────────────────────────┐    │  ┌────────────────────┐ │
│  │  Prompt 文本输入框       │    │  │                    │ │
│  │  [+图片/视频参考]        │    │  │   生成结果网格      │ │
│  │                         │    │  │   可点击放大/编辑   │ │
│  └─────────────────────────┘    │  │                    │ │
│                                  │  └────────────────────┘ │
│  [参数区，默认折叠]              │                          │
│  - 时长 | 分辨率 | 风格 | ...  │                          │
│                                  │                          │
│  [生成按钮 (大而醒目)]           │                          │
│                                  │                          │
└──────────────────────────────────┴──────────────────────────┘
```

#### 信息架构特点
- **输入→输出**：最简化的工作流，没有复杂节点/时间线
- **参数折叠**：高级参数默认收起，普通用户不需要关心
- **历史作品流**：右侧自然展示历史生成结果，瀑布流布局
- **一键编辑**：对结果可以直接"延长"、"放大"、"重绘"，无需重新输入

#### 视觉风格
- **超现代极简**：大量留白，几乎没有边框
- **渐变按钮**：主 CTA 使用微妙渐变色，吸引点击
- **卡片悬浮**：结果卡片 hover 时轻微上浮，交互反馈清晰
- **渐进披露**：功能按需展开，避免界面拥挤

#### 配色方案
| 色值 | 用途 |
|------|------|
| `#FFFFFF` | 背景 |
| `#FAFAFA` | 输入区背景 |
| `#FF6B6B` → `#FF8E53` (橙红渐变) | 主 CTA 按钮 |
| `#000000` | 主文字 |
| `#6B7280` | 次要文字、占位符 |
| `#F3F4F6` | 卡片背景、分割区域 |

## 三、AI 创作一体化平台深度分析

### 3.1 Midjourney v7 (2025 年 12 月大改版)

#### 设计理念
- **从 Discord 解放**：首次拥有独立 Web 应用，告别纯聊天式交互
- **画廊优先**：用户核心需求是浏览、管理、迭代作品，画廊是首页
- **通用侧边栏**：所有设置、工具、选项集中在侧边栏，而非分散下拉菜单

#### 功能布局（侧边栏 + 画廊 + 创作面板）
```
┌─────────────────────────────────────────────────────────────┐
│  [顶部栏] 搜索 | 通知 | 升级 | 用户头像                     │
├──────────┬──────────────────────────────────────────────────┤
│          │                                                  │
│ 左侧导航 │              主内容区                             │
│          │                                                  │
│ 🏠 首页   │  [创作面板 (顶部，可收起)]                        │
│ 🖼 画廊   │  ┌─────────────────────────────────────────┐  │
│ 📁 合集   │  │  Prompt 输入 [+参考图] [参数设置] [生成] │  │
│ ⚙️ 设置   │  └─────────────────────────────────────────┘  │
│ 📊 用量   │                                                  │
│ 🌙 主题   │  ┌─────────────────────────────────────────┐  │
│          │  │                                         │  │
│          │  │           作品画廊网格                   │  │
│          │  │     (无限滚动，可筛选/排序)              │  │
│          │  │                                         │  │
│          │  └─────────────────────────────────────────┘  │
│          │                                                  │
└──────────┴──────────────────────────────────────────────────┘
```

#### 信息架构特点
- **画廊是核心**：登录后首先看到自己的作品墙，而非空白输入框
- **全局创作入口**：顶部创作面板可随时唤起，不打断浏览
- **侧边栏整合**：将 Discord 时代散落在各处的 `/settings`、`/prefer` 等命令整合为可视化设置
- **深色模式支持**：完美适配 System / Light / Dark 三种主题

#### 视觉风格
- **艺术画廊质感**：作品之间间距充足，像在画廊看展
- **极简 UI 框架**：UI 元素极低饱和度，不抢作品风头
- **精致控件**：滑块、复选框、下拉菜单都经过精心设计
- **流畅动画**：作品加载、面板展开、主题切换都有平滑过渡

#### 配色方案（浅色主题）
| 色值 | 用途 |
|------|------|
| `#FFFFFF` | 背景 |
| `#F9FAFB` | 侧边栏背景 |
| `#111827` | 主文字 |
| `#6B7280` | 次要文字 |
| `#5B5FC7` (紫) | Midjourney 品牌色、强调 |
| `#E5E7EB` | 边框、分割线 |
| `#F3F4F6` | 卡片悬停背景 |

### 3.2 ComfyUI

#### 设计理念
- **节点式工作流事实标准**：完全可视化的编程，每个节点是一个函数
- **灵活性至上**：任何工作流都可以搭建，没有限制
- **App Mode 演进**：认识到原生节点界面太复杂，推出 App Mode 简化 UI

#### 功能布局（经典节点编辑器）
```
┌─────────────────────────────────────────────────────────────┐
│  [顶部菜单栏] 文件 | 编辑 | 工作流 | 视图 | 帮助             │
├──────────┬──────────────────────────────────┬───────────────┤
│          │                                  │               │
│ 节点库侧栏│       无限节点画布               │  属性/队列侧栏 │
│ (可折叠)  │                                  │  (可折叠)     │
│          │  ○ 节点1 ────连线──→ ○ 节点2     │               │
│ - 加载器 │      ↓                          │ - 队列Prompt  │
│ - 条件   │      ↓                          │ - 历史记录    │
│ - 采样器 │  ○ 节点3 ─────────────→ ○ 节点4 │ - 节点信息    │
│ - 解码器 │                                  │               │
│ - 保存器 │  [迷你地图]                      │               │
│          │                                  │               │
├──────────┴──────────────────────────────────┴───────────────┤
│  [底部状态栏] 队列: 0 | 模型加载状态 | 进度 | VRAM 使用       │
└─────────────────────────────────────────────────────────────┘
```

#### 信息架构特点（原生模式）
- **节点库搜索**：双击画布弹出节点搜索框，快速添加
- **连线分类**：不同颜色连线表示不同数据类型（模型/条件/图像/数值）
- **分组功能**：可以将多个节点框选为组，折叠/着色/注释
- **Reroute 节点**：优化连线走向，避免 spaghetti 式混乱连线

#### App Mode（简化模式）
```
┌─────────────────────────────────────────────────────────────┐
│  [工作流标题] 导出 | 运行                                   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  [简洁表单界面]                                              │
│  ┌─────────────────────────────────────────────────────┐  │
│  │  上传图片: [___________________________] [选择文件]  │  │
│  │  Prompt:  [______________________________________]  │  │
│  │  步数:    [====●========] 30                        │  │
│  │  CFG:     [==●==========] 7                         │  │
│  │  [大的「生成」按钮]                                   │  │
│  └─────────────────────────────────────────────────────┘  │
│                                                             │
│  [结果预览区]                                                │
│  ┌─────────────────────────────────────────────────────┐  │
│  │                                                     │  │
│  │                  生成结果图片                        │  │
│  │                                                     │  │
│  └─────────────────────────────────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
- **隐藏节点图**：终端用户看不到复杂节点，只看到表单化界面
- **工作流即应用**：创作者搭建工作流，发布为 App 给普通用户使用
- **一键执行**：填参数→点运行→看结果，零学习成本

#### 视觉风格
- **经典 IDE 风**：深色背景，彩色连线，类似 Blender / Nuke
- **功能优先**：UI 装饰极少，信息密度高
- **彩色语义**：连线颜色=数据类型，节点颜色=功能分类
- **实用主义**：不追求花哨，效率第一

#### 配色方案
| 色值 | 用途 |
|------|------|
| `#202020` | 画布背景 |
| `#353535` | 节点背景 |
| `#505050` | 节点标题栏 |

### 4.1 设计理念对比

| 平台 | 核心隐喻 | 目标用户 | 学习曲线 |

### 4.2 布局模式总结

| 布局模式 | 代表平台 | 优点 | 缺点 | 适用场景 |
|----------|----------|------|------|----------|
| **三栏+无限画布** | 可灵、即梦、ComfyUI | 灵活、功能全面、可视化逻辑 | 对新手复杂、信息密度高 | 复杂工作流、多步骤任务 |
| **专业四分区**（素材+预览+参数+时间线） | Runway | 符合专业工具习惯、时间线直观 | 界面复杂、屏幕空间要求高 | 视频剪辑、时间相关创作 |
| **两栏极简**（输入+输出） | Pika | 简单直观、零学习成本 | 灵活性差、复杂任务难表达 | 快速生成、单步任务 |
| **侧边栏+画廊** | Midjourney | 作品驱动、浏览体验好 | 创作入口较深 | 作品管理、迭代优化 |
| **自动布局流程图** | Dify | 线性逻辑清晰、自动整理 | 自由度低、不适合自由画布 | 有明确顺序的流程、分支逻辑 |

### 4.3 配色趋势观察

#### 2025-2026 主流设计趋势
1. **中性色优先**：从 `#FFFFFF` 到 `#F9FAFB` 到 `#F3F4F6` 的灰度层级，而非纯白纯灰
2. **品牌色克制使用**：仅用于 CTA、选中态、高亮，不大面积使用
3. **功能色标准化**：
   - 成功/运行中：绿色系（`#12B76A` / `#34C759`）
   - 警告/排队：橙色系（`#F79009` / `#FF9500`）
   - 错误/失败：红色系（`#F04438` / `#FF3B30`）
   - 信息/链接：蓝色系（`#155EEF` / `#007AFF`）
4. **深色主题是专业工具标配**，但必须提供浅色主题选项
5. **渐变色退潮**：除 Pika 等少数主打年轻用户的产品，多数使用纯色或极微妙渐变
6. **边框极淡化**：1px `#EAECF0` / `#E5E7EB` 浅边框，或用阴影/背景差代替边框

#### 字体趋势
- **无衬线一统天下**：Inter（Web）、SF Pro（Apple 生态）、Roboto（Google 生态）
- **字号层级清晰**：通常 5-6 级层级（12px/13px/14px/16px/20px/24px+）
- **字重对比**：Regular(400) 正文、Medium(500) 按钮/标题、Semibold(600) 强调

#### 空间与圆角
- **8px 网格系统**：所有间距、尺寸都是 8 的倍数（8/12/16/24/32/48）
- **圆角分层**：
  - 小控件（按钮/标签/输入框）：6-8px
  - 卡片/面板：12-16px
  - 大容器/模态：20-24px
- **留白充足**：元素间距从过去的紧凑（8-12px）转向宽松（16-24px）

### 4.4 交互模式最佳实践

| 交互模式 | 采用平台 | 说明 |
|----------|----------|------|
| **无限画布 + 迷你地图** | 可灵、即梦、ComfyUI | 复杂工作流必备，提供全局导航 |
| **上下文敏感侧边栏** | Runway、Dify | 选中什么显示什么，减少 UI 噪音 |
| **渐进式披露** | Pika、Midjourney | 高级功能默认隐藏，按需展开 |
| **自动布局** | Dify | 减少用户手动对齐成本，适合线性流程 |
| **节点/作品卡片悬浮效果** | 全部 | hover 时上浮/加阴影，暗示可交互 |
| **生成进度可视化** | 全部 | 进度条 + 百分比 + 状态文字，必要时中间状态预览 |
| **深色/浅色主题切换** | Midjourney、Dify | 尊重系统设置，提供手动切换 |
| **响应式三栏适配** | Dify | 小屏幕自动折叠侧栏，保证可用性 |

## 五、对 ToIV 的启示与设计方向建议

### 5.1 ToIV 当前问题诊断（结合用户反馈）

1. **界面不够简洁，冗余元素多**
   - ✅ 参考：Pika 的渐进式披露、Midjourney 的画廊优先
   - ❌ 避免：ComfyUI 原生的高信息密度、Runway 全功能展开

2. **功能实现效果不佳，体验不流畅**
   - ✅ 参考：即梦的预测式交互、Runway 的专业时间线
   - ❌ 避免：频繁页面跳转、模态框嵌套

3. **页面排版混乱，信息层级不清晰**
   - ✅ 参考：Dify 的三栏结构清晰分区、可灵的节点卡片化
   - ❌ 避免：多控件随意堆叠、对齐不一致

4. **UI 缺乏美感，视觉吸引力不足**
   - ✅ 参考：Midjourney 的画廊质感、即梦的轻盈现代
   - ❌ 避免：高饱和度刺眼颜色、过多渐变/动画

5. **配色不协调，不符合现代审美**
   - ✅ 参考：2025-2026 中性色+克制品牌色趋势
   - ❌ 避免：彩虹色、大面积高饱和、无功能色体系

### 5.2 核心设计原则（建议采纳）

基于竞品分析 + 用户偏好（浅色主题、简约优雅、Film Atelier 暗房隐喻、UI 隐退内容焦点）：

1. **「创作工作室」隐喻**
   - 类比暗房/剪辑台/导演工作台，而非 SaaS 后台
   - UI 是"工作台面"，内容（素材/节点/结果）是"作品"
   - 控件是"工具"，需要时拿起，不需要时放在一边

2. **浅色主题优先**
   - 以 `#FAFAFA` ~ `#F5F5F5` 为画布背景
   - 白色卡片 + 极浅阴影构建层级
   - 提供深色主题切换（可选）

3. **三栏结构为骨架**
   - **左侧**：工具/导航/节点库（可折叠为图标栏）
   - **中央**：画布/时间线/预览（核心创作区，占 60%+ 宽度）
   - **右侧**：上下文敏感属性面板（无选中时可折叠）

4. **节点画布 + 时间线双模式**
   - **节点模式**（可灵/ComfyUI 式）：适合多模型、多步骤、非线 性工作流（图生视频→配音→剪辑）
   - **时间线模式**（Runway 式）：适合短剧分镜→片段→成片的线性组装
   - 两种模式无缝切换，数据共享

5. **克制的视觉语言**
   - **颜色**：中性色为主，单一品牌色（建议低饱和靛蓝/墨绿），功能色标准化
   - **动画**：仅在状态变化时使用（200-300ms，ease-out），拒绝炫技
   - **图标**：Lucide React（已规范），统一线性风格
   - **字体**：Inter（或系统无衬线），清晰字号层级

6. **渐进式复杂度**
   - **新手模式**：Pika 式简洁表单，填 Prompt→选参数→生成
   - **进阶模式**：可灵式节点画布，自定义工作流
   - **专业模式**：Runway 式时间线 + Inspector，帧级精度编辑
   - 用户可切换，默认根据使用频率智能推荐

## 六、待决策事项

基于本分析，需要与用户确认以下方向，以便进入方案设计阶段：

1. **核心布局选择**：
   - A. 三栏无限画布（可灵/即梦式，最灵活）
   - B. 四分区专业工作室（Runway式，视频导向）
   - C. 双模式可切换（画布+时间线，最全面但复杂度高）

2. **品牌主色调方向**：
   - A. 墨绿/靛蓝（沉稳专业，电影感）
   - B. 暖橙/砖红（创作活力，暗房感）
   - C. 保持中性灰（最极简，内容突出）

3. **默认主题**：
   - A. 浅色主题默认（符合用户偏好）
   - B. 自动跟随系统
   - C. 深色主题默认（专业工具标配）

4. **重构范围优先级**：
   - A. 先统一设计系统（颜色/字体/间距/组件），再改页面
   - B. 先改核心工作台（画布/创作页），再改其他页面
   - C. 全面同时重构（风险高但一致性好）
