# VideoView 三栏工作室布局重构设计

## 背景

当前 `/?view=video` 页面采用单列左对齐表单，存在以下体验问题：

1. 左侧控制区元素垂直堆叠，缺乏栅格与分组，视觉层级混乱。
2. 上传参考图区域占据过大，提示词输入框宽度受限。
3. 参数行（分辨率、时长、FPS、种子）仅靠 `align-items: center` 硬撑，标签与控件未对齐。
4. active 预设按钮使用纯白底黑字，在深色主题下突兀。
5. 右侧大片空白未利用，生成结果与历史任务无专门区域。
6. 参考图为必填项，无法直接进行文生视频。

## 目标

- 将视频生成页面重构为**三栏工作室布局**：左侧参数、中间预览、右侧状态/历史。
- 保持当前 dark 主题不变。
- 将参考图从必填改为可选，支持纯文生视频。
- 统一视觉层级、间距、配色，消除杂乱感。

## 方案

### 布局

```
┌─────────────────┬──────────────────────────────┬─────────────────┐
│   左栏 280px    │         中间 自适应           │   右栏 260px    │
│   参数面板       │         预览/画布             │   状态/历史      │
│   (固定)        │         (主视觉区)            │   (固定)        │
└─────────────────┴──────────────────────────────┴─────────────────┘
```

- 左栏：固定宽度 280px，垂直滚动。
- 中间：自适应剩余宽度，承载预览与结果。
- 右栏：固定宽度 260px，显示当前任务与历史。

### 左栏 — 参数面板

1. **模式切换（顶部）**
   - `文生视频` / `图生视频` 两个 pill 按钮。
   - 默认选中“图生视频”（兼容现有行为）。
   - 选“文生视频”时隐藏参考图上传区。

2. **提示词输入框**
   - 占满左栏宽度，高度 96px。
   - placeholder 使用 `var(--ink-soft)` 弱化。

3. **参考图上传区（仅在图生视频模式显示）**
   - 缩小为 16:9 卡片，最大高度 140px。
   - 未上传：显示“+ 添加参考图”。
   - 已上传：显示缩略图，hover 显示“更换 / 删除”。

4. **参数分组卡片**
   - 每个分组使用 `var(--bg-1)` 背景 + `var(--hairline)` 边框的卡片容器。
   - 分辨率：横向 pill 组（832×480 / 640×480 / 1280×720）。
   - 时长：横向 pill 组（49帧 / 81帧 / 105帧）。
   - FPS：数字输入框，宽度 80px。
   - 种子：折叠行，勾选后展开输入框。

5. **生成按钮**
   - 左栏底部固定，占满宽度。
   - loading 时按钮内嵌细进度条，文字显示“生成中 34%”。

### 中间 — 预览区

- **空态**：大字号提示 + 轻 icon，居中显示。
- **参考图预览**：图生模式时居中显示，带“参考图”标签。
- **生成中**：居中进度环 + 当前阶段文字。
- **结果视频**：生成完成后全区域播放，下方显示参数摘要（分辨率、时长、FPS、种子）。

### 右栏 — 状态与历史

- **当前任务**：状态 badge + 进度条 + 预计剩余时间。
- **最近生成**：历史视频缩略图列表（最近 5 条）。
- **快捷操作**：重新生成、下载、删除（仅对已完成任务）。

### 视觉规范

- 背景：`var(--bg-0)` 作为页面底，`var(--bg-1)` 作为卡片底。
- 边框：`var(--hairline)`，圆角统一使用 `var(--radius-md)` / `var(--radius-lg)`。
- 标签：统一使用 `var(--ink-soft)`，字号 0.75rem，字重 500。
- active 状态：半透明 accent 背景（如 `rgba(var(--accent-rgb), 0.15)`）+ accent 文字，替代纯白底。
- 间距：分组间距 `var(--space-4)`，组内间距 `var(--space-3)`。
- 按钮：主按钮使用 `var(--accent)`，禁用状态使用 `var(--bg-2)` + `var(--ink-soft)`。

### 功能改动

- 将参考图从必填改为可选：
  - `handleGenerate` 不再检查 `uploadedFilename`。
  - 未上传图片时调用后端文生视频接口（若后端 `generateVideo` 需要 `image` 字段，传空字符串或不传）。
  - 已上传图片时维持现有 img2video 逻辑。
- 提示词仍必填。

## 影响范围

- 主要文件：`apps/web/components/create/VideoView.tsx`
- 依赖：`@/lib/api` 中的 `generateVideo` 类型可能需要支持可选 `image`。
- 不改动后端逻辑，仅前端调用方式调整。

## 验收标准

- [ ] 页面呈现三栏布局，左/右栏固定宽度，中间自适应。
- [ ] 文生视频 / 图生视频模式可切换，参考图可选。
- [ ] 参数卡片分组清晰，active 预设使用半透明 accent 样式。
- [ ] 生成按钮 loading 状态显示进度。
- [ ] 生成结果在中间区域播放。
- [ ] 右侧显示当前任务状态与最近历史。
- [ ] `tsc --noEmit` 与 `npm run build` 通过。
