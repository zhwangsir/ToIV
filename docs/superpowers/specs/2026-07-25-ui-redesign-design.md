## 一、设计理念

### 1.1 核心隐喻：Film Atelier（电影创作工作室）
- **暗房/剪辑台/导演工作台**，而非 SaaS 后台
- UI 是"工作台面"——必要时存在，不需要时隐退
- 内容（素材、节点、预览、时间线）是"作品"——绝对视觉焦点
- 控件是"工具"——需要时拿起，不需要时放在一边

### 1.2 设计原则
1. **内容优先**：中性灰配色，无彩色干扰，所有UI元素服务于内容展示
2. **渐进式复杂度**：新手简洁表单 → 进阶节点画布 → 专业时间线
3. **无缝切换**：画布模式↔工作室模式不丢失上下文
4. **创作区始终最大**：任何断降下中央创作区域占比≥50%
5. **克制动效**：仅状态变化时使用（200-300ms ease-out），拒绝炫技
6. **一致性**：8px网格系统、统一圆角层级、统一组件规范

## 三、核心布局规范

### 3.1 全局结构

所有页面共享以下结构：
```
┌─────────────────────────────────────────────────────────┐
│  [TopBar] 高度40px(桌面)/48px(移动)                     │
├────┬────────────────────────────────────────┬───────────┤
│    │                                        │           │
│ S  │           主内容区（可滚动）            │  Right    │
│ i  │                                        │  Panel    │
│ d  │    [Canvas Mode / Studio Mode]         │  (可折叠) │
│ e  │                                        │           │
│ B  │                                        │           │
│ a  │                                        │           │
│ r  │                                        │           │
│    │                                        │           │
├────┴────────────────────────────────────────┴───────────┤
│  [BottomNav] 仅 <768px 显示，高度52px（含安全区）        │
└─────────────────────────────────────────────────────────┘
```

- **SideBar**：56px宽（图标栏），桌面端可展开为200-220px宽面板
- **Right Panel**：200-220px宽，上下文敏感，无选中时可折叠为4px触发条
- **主内容区**：flex:1，背景为点阵网格（画布模式）或纯色（工作室模式预览区）
- **模式切换器**：固定在主内容区顶部中央，胶囊形状

### 3.2 模式 A：节点画布模式（Canvas Mode）

```
┌─────────────────────────────────────────────────────────┐
│ TopBar: Logo | 导航 | 项目选择 | 用户                    │
├────┬─────────────┬──────────────────────┬───────────────┤
│    │             │  [模式切换器]         │               │
│ S  │  节点库     │   ┌─────┐   ┌─────┐  │   属性面板    │
│ i  │  素材       │   │Prompt│──→│视频 │  │               │
│ d  │             │   └─────┘   └─────┘  │  - 模型       │
│ e  │  [可折叠]   │                      │  - 参数       │
│ B  │             │     中央无限画布      │  - 运行按钮    │
│ a  │             │     (点阵背景)        │               │
│ r  │             │                      │  [可折叠]     │
│    │             │  [迷你地图][缩放控制] │               │
└────┴─────────────┴──────────────────────┴───────────────┘
```

**画布特性**：
- 背景：`#FAFAFA` + 1px 点阵，间距20px，点色`#E0E0E0`
- 节点卡片：白底，`--radius-lg`圆角，`--shadow-sm`阴影
- 连线：1.5px，贝塞尔曲线，默认`#CCC`，运行中高亮为`--color-accent`
- 选中节点：边框变`--color-accent`，阴影升级为`--shadow-md`
- 运行中节点：左上角显示loading旋转图标，进度条在节点底部

### 3.3 模式 B：工作室模式（Studio Mode）

```
┌─────────────────────────────────────────────────────────┐
│ TopBar: Logo | 导航 | 项目选择 | 用户                    │
├────┬─────────────┬──────────────────────┬───────────────┤
│    │             │  [模式切换器]  [播放控制]│              │
│ S  │  媒体池     │                      │   Inspector   │
│ i  │             │    ┌────────────┐    │               │
│ d  │  - 全部     │    │            │    │  - 缩放/位置  │
│ e  │  - 视频     │    │  预览窗口  │    │  - 音量/转场  │
│ B  │  - 图片     │    │  (深色)    │    │  - 特效       │
│ a  │  - 音频     │    │            │    │               │
│ r  │             │    └────────────┘    │               │
│    │             ├──────────────────────┤               │
│    │             │   时间线区域（深色）  │               │
│    │             │  ┌─────────────────┐ │               │
│    │             │  │V1 [][][]        │ │               │
│    │             │  │A1 ~~~~~~~~~~~~  │ │               │
│    │             │  └─────────────────┘ │               │
└────┴─────────────┴──────────────────────┴───────────────┘
```

**工作室特性**：
- 预览窗口：深色背景`#1A1A1A`，视频内容居中，底部进度条
- 时间线区域：`#252525`深色，视频轨`#444`、音频轨`#2A3A2A`，播放头红色竖线
- 媒体池：网格布局缩略图，hover显示时长/分辨率标签
- Inspector：选中片段时显示对应参数，无选中时显示全局设置

## 四、响应式断点规范

### 4.1 断点定义

| 名称 | 断点 | 目标设备 | SideBar | Right Panel | 导航 |
|------|------|----------|---------|-------------|------|
| 大屏桌面 | ≥1440px | 27" 4K、iMac | 56px图标+220px展开 | 220px固定 | 顶部栏完整 |
| 标准桌面 | 1024-1439px | MacBook 13"、1080p | 48px图标+180px展开 | 180px固定 | 顶部栏简化 |
| 平板横屏 | 768-1023px | iPad 横屏 | 48px图标 | 浮动抽屉（点按钮呼出） | 顶部栏精简 |
| 平板竖屏 | 576-767px | iPad mini竖屏 | 抽屉（汉堡菜单） | 底部Sheet | 底部Tab栏 |
| 移动端 | <576px | iPhone/Android | 抽屉（汉堡菜单） | 全屏模态 | 底部Tab+中间凸起CTA |

### 4.2 各断点详细规则

#### 大屏桌面 ≥1440px
- 左侧：56px图标栏可展开为220px节点/素材库
- 右侧：220px属性/Inspector面板常驻
- 中央画布占比约55%
- 节点卡片尺寸：宽180px
- 字体使用基础大小

#### 标准桌面 1024-1439px
- 左侧：48px图标栏可展开为180px面板
- 右侧：180px属性面板常驻
- 中央画布占比约60%
- 节点卡片尺寸：宽160px
- 间距缩进一级（用--space-3替代--space-4）

#### 平板横屏 768-1023px
- 左侧：仅48px图标栏常驻，节点库/素材库改为顶部下拉抽屉
- 右侧：属性面板改为右侧滑出抽屉（齿轮按钮触发），蒙层`--overlay-strong`
- 中央画布占比约75%
- 模式切换器尺寸缩小
- 触控目标≥32×32px

#### 平板竖屏 576-767px
- 顶部：简化TopBar，仅Logo+汉堡菜单+用户
- 中央：全屏画布/预览，占比100%
- 左侧：抽屉式导航，点击汉堡菜单滑入
- 右侧：属性改为底部Sheet（从底部滑出300px高）
- 底部：44px高Tab栏（工作台/素材/+/项目/我的）
- 触控目标≥44×44px

#### 移动端 <576px
- 顶部：48px高状态栏，居中显示模式切换器
- 中央：全屏创作区
- 底部：52px高Tab栏（含iPhone安全区），中间"+"按钮凸起8px
- 节点库/素材/属性均为全屏模态
- 画布支持双指缩放、双击适应
- 预览区支持横屏自动旋转（lock至横屏全屏）
- 触控目标≥48×48px

### 4.3 横竖屏切换
- **状态保持**：切换时保留选中节点、画布位置/缩放、播放进度、运行任务
- **横屏优先两栏**：即使是手机，横屏时也采用类似平板横屏的布局（图标栏+全屏画布）
- **竖屏单栏优先**：所有竖屏设备均采用单栏+底部Tab
- **安全区域**：使用`env(safe-area-inset-*)`适配刘海屏/打孔屏/底栏

### 4.4 字体缩放
- 支持系统字体大小±2级
- 最小字号不小于11px
- 关键按钮/触控区域不随字体缩放改变最小尺寸（44px）

## 五、组件规范

### 5.1 按钮（Button）

| 变体 | 用途 | 样式 |
|------|------|------|
| Primary | 主要CTA（运行/生成/保存） | `bg-accent text-white radius-md shadow-sm`，hover加深10% |
| Secondary | 次要操作（取消/重置） | `bg-bg-surface border border-border text-primary` |
| Ghost | 工具栏/图标按钮 | `bg-transparent hover:bg-bg-subtle` |
| Destructive | 删除/危险操作 | `bg-error text-white` |

尺寸规范：
- Large：高40px，px-5，text-md
- Medium：高32px，px-4，text-sm（默认）
- Small：高24px，px-3，text-xs
- Icon：32×32px（桌面）/40×40px（平板）/44×44px（移动）

### 5.2 输入框（Input）
- 高度：32px（桌面）/40px（移动）
- 背景：`--color-bg-subtle`
- 边框：focus时1px `--color-accent`，默认无或1px `--color-border-subtle`
- 圆角：`--radius-md`
- Placeholder：`--color-text-tertiary`

### 5.3 节点卡片（Node Card）
- 最小宽度：160px（桌面）
- 结构：
  - 标题栏：32px高，节点名称+状态图标
  - 内容区：自适应高度，输入/输出/参数/预览
  - 操作栏：28px高，运行按钮+更多菜单
- 端口：左入右出，直径10px圆点，颜色对应数据类型
- 状态：
  - Idle：默认样式
  - Running：标题栏显示loading旋转图标，底部进度条
  - Success：运行按钮变绿勾选
  - Error：边框变红，错误图标

### 5.4 模式切换器（Mode Switcher）
- 胶囊形状：`--radius-full`
- 背景：`--color-bg-surface` + `--shadow-md`
- 内部padding：3px
- 选项padding：8px 16px
- 选中项：`bg-accent text-white --radius-md`
- 固定位置：主内容区顶部居中，top:12px

### 5.5 Tab栏（Bottom Navigation，仅移动端）
- 高度：52px + `env(safe-area-inset-bottom)`
- 背景：`--color-bg-surface` + 顶部1px `--color-border`
- 结构：5个均等位置，中间CTA凸起
- 中间CTA：直径56px圆形，`bg-accent text-white shadow-lg`，向上凸起12px
- 选中态：图标+文字使用`--color-accent`，未选中`--color-text-tertiary`
- 图标尺寸：24×24px

### 5.6 Tooltip
- 背景：`rgba(0,0,0,0.8)`（浅色主题）/`rgba(255,255,255,0.9)`（深色主题）
- 文字：白色（浅色）/黑色（深色），text-xs
- 圆角：`--radius-md`
- 出现延迟：300ms hover后
- 位置：默认在元素下方8px

### 5.7 Toast通知
- 位置：右上角（桌面）/顶部居中（移动）
- 宽度：自动（最大320px）
- 结构：图标+文字+关闭按钮
- 类型对应图标：Success(✓)、Warning(⚠)、Error(✕)、Info(ℹ)
- 自动消失：Success/Info 3s，Warning/Error 需手动关闭

## 六、深浅主题切换

### 6.1 主题策略
- 默认：`auto`（跟随系统`prefers-color-scheme`）
- 可选：`light` / `dark` / `auto`
- 设置位置：侧边栏底部/用户菜单
- 切换动画：200ms平滑过渡（`transition: background-color 200ms, color 200ms`）
- 记忆：`localStorage`存储用户选择

### 6.2 特殊处理
- **工作室模式预览区**：始终深色，不受主题影响（视频观看需要暗色环境）
- **工作室模式时间线**：始终深色
- **图片/视频内容**：不变色，保持原始色彩
- **画布点阵**：浅色主题用灰色点，深色主题用稍浅的深灰点（保持低对比）

## 八、资源加载与质量规范

### 8.1 图标
- 全部使用Lucide React，按需引入，禁止其他图标库
- 尺寸统一：16px(小)/18px(中)/24px(大)
- strokeWidth默认1.75，按钮图标使用2
- 禁止emoji作为图标

### 8.2 图片
- 缩略图：WebP格式，质量80，长边≤512px
- 预览图：WebP格式，质量85，长边≤1920px
- 原图：保持原始格式
- 懒加载：所有非首屏图片使用`loading="lazy"`
- 占位符：低质量模糊占位（LQIP）或骨架屏

### 8.3 动画性能
- 优先使用`transform`和`opacity`（GPU加速）
- 避免动画期间layout thrash（不触发reflow）
- 使用`will-change`适度提示浏览器优化
- 尊重`prefers-reduced-motion`：关闭所有非必要动画
