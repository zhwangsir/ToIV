## 三、审计抓到的最重要的四个隐藏 bug

1. **v2 单候选分镜永不回写**:`generate-video-v2` 单候选分支漏挂回写任务,shot 永久卡「生成中」直到前端 15 分钟超时。已修。
2. **场景 LoRA 从不生效**:10 个场景预设的 LoRA 在 FLUX.2 等 nextgen 分支被**静默丢弃**(builder 根本没有 loras 参数),42 个 LoRA 资产零贡献。已修(lora_chain 接入 + 标签解析器)。
3. **全部短剧视频(含全年龄)用 NSFW 成人底模 10Eros**:硬编码。已改为请求级 `nsfw` 开关,SFW 默认 ltx-2.3-distilled。
4. **seed 字段 int64 溢出 PG**(迁移实测发现,审计都漏了):MAX_SEED=2^63-1 超 PG int4,4 个字段改 BigInteger。已修。

## 五、运维速查(管家日常用)

- **部署**:`./deploy/deploy.sh`(现在失败会真的报错退出,不再假阳性);回滚:`./deploy/deploy.sh --rollback`
