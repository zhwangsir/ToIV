## 3. P2 — 短剧主路径（阶段轨 · 声画 · 定妆 · 管线）

> 粗估 5–8 人天。  
> **不做：** 竖排流水线画布（P3）；剪映/FCPXML（P4）；进门自由画布。  
> 假设 待拍板 **D6-A / D5-A / D7-A / D4-C**。

### 3.1 阶段状态机（产品层）

```
[剧本] → [资产/定妆] → [分镜准备] → [生成] → [配音] → [对口型] → [合成]
              │              │           │         │          │
              │              │           │         │          └─ assembly_gate（人闸③）
              │              │           │         └─ 无台词？→ 越过 voice&lipsync（标「无对白」）
              │              │           └─ 人闸②：脸/VLM 门禁通过才级联
              │              └─ prepared：refs+prompt 齐；≠ queued/rendering
              └─ 人闸①：定妆选角确认（锁 reference）
```

**与代码状态对齐（勿臆造新枚举也可先做）：**

| 产品阶段 | Studio shot.status 主要信号 | 额外产品条件 |
|----------|----------------------------|--------------|
| 分镜准备·未就绪 | `draft` 且缺 refs/prompt | 禁止批量生成 CTA |
| 分镜准备·已就绪 | `draft` + refs 齐（产品称 prepared） | 可点「开始生成」 |
| 生成中 | `queued` / `rendering` | 忙态 |
| 已出视频 | `rendered` | 进入配音或越过 |
| 配音 | → `voiced` | 无台词：直接视为越过 |
| 对口型 | → `lipsynced` | 可跳过并标注 |
| 完成 | `done` | 可进合成 |

`prepared ≠ generating`：**UI 必须两态分色分文案**；不得用同一「进行中」绿。

#### ① 剧本 `script`

## 4. P3 — 受控节点体验（双视图 · 添加菜单 · 检视器）

> 粗估 6–10 人天。  
> 假设 待拍板 **D2-A**。  
> **不做：** 默认新建进统一画布（D1-B）；3D 导演台；在添加菜单挂「本地·H3:8264」。

### 4.1 节点感边界（先讲清楚）

| 层 | 是什么 | 不是什么 |
|----|--------|----------|
| **短剧流水线视图** | 列表真源的**竖排投影**：每行≈文本→首/尾帧→视频（+配音/口型状态点） | 无限自由图；可乱连任意端口 |
| **自由画布（专家）** | 可自由加节点/工作流；参数右侧检视器 | 学习站默认壳；引擎名一级菜单 |
| **禁止** | 把短剧 ws 整页 REPLACE 成 xyflow | Toonflow / TapCanvas 进门即画布 |

### 4.2 列表 ↔ 竖排双视图

**入口：** 工作区顶栏二级切换：`列表 | 流水线视图`（默认列表）。

**同源字段（投影只读+可写的字段集合）：**

| 字段 | 列表 | 竖排节点 | 可写侧 |
|------|------|----------|--------|
| shotId / 序号 | ✓ | ✓ | 列表排序 / timeline |
| 文本 / 提示语 | ✓ | 文本节点 | 双侧 |
| 首帧/尾帧 URL | ✓ | 帧节点 | 双侧 |
| video_url | ✓ | 视频节点 | 生成动作 |
| voice / lipsync 状态 | badge | 节点脚标 | 动作按钮 |
| pipeline | 行内或检视器 | 检视器 | 检视器 |
| 定妆 refs | 资产链 | 节点「参考」槽 | 资产阶段 |
| layout x/y | — | 仅 metadata | 仅画布 |

**规则：** 业务数据单源（Studio shots）；`canvas_layout` / `workflow_groups` 仅布局元数据（对齐 LocalMiniDrama）。列表改文本 → 竖排同步；禁止双写冲突。

**空/忙/失败（流水线视图）：**

| 态 | UI |
|----|-----|
| 空 | ≥1 模板条：「从当前分镜生成流水线投影」 |
| 忙 | 节点脉动=generating；连线不改业务 |
| 失败 | 节点边框 error + 检视器人话；「重试」写回同一 shot |

### 4.3 自由画布：添加菜单创作语义（G6）

**一级类型（目标）：** 文本 / 图像 / 视频 / 音频 / 合成 / 分组（+ 上传/素材等资源区 KEEP）。

**映射（现 → 目标）：**

| 现 `LOCAL_CREATE_PRESETS` 标签 | 目标 |
|-------------------------------|------|
| 本地·出图 | → 一级「图像」；默认模型=本地出图（设置里改） |
| 本地·H3 / Wan / LongCat / VACE / Animate2 / Continue / Avatar | → **删除一级**；并入「视频」节点的**模型下拉** |
| 智能剪辑/逐帧/脚本（developing） | → 实验室或隐藏；不挡主路径 |

**验收：** 添加菜单一级无「本地·H3」「本地·Wan」等引擎型号；无 `:8264`。

### 4.4 右侧检视器（G5）
