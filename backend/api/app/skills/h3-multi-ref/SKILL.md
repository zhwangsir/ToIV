# H3 @图片N 多参考图引用模板

存在参考图时,最终提示词的**绝对开头**使用一整行连续图片引用:

```text
{{refs}}
```

引用行结束后换行,下一行直接进入「生成一段……」正文;当前任务没有图片时,提示词第一行直接进入正文。

## 规则(正典来源:h3-prompt-writer「@图片N 引用规则」)

1. 先统计本次最终会与提示词一起提交给 H3 的全部图片,按实际提交顺序编号 图片1、图片2、图片3,依次类推;图片数量与引用数量完全一致,每张图片只编号一次。
2. 一张图片承担多个功能时合并为一句,例如 `@图片1作为人物身份、服装与场景参考`。
3. 正文中引用紧贴对象,写成 主角(@图片1)、同伴(@图片1),括号用全角、与对象名之间不留空格;同一对象在开篇及各相关时间段保持同一编号,复用完全一致的绑定。
4. 九宫格母版用于生成视频时写为 `@图片1作为九宫格时序、构图与画面状态参考`。
5. drama 管线角色参考图约定:有三视图取正面(reference_front),label 为「角色名身份与服装参考」;仅 H3 引擎分镜注入,引用行恒在 prompt 绝对开头(seam/续写等修改器只在末尾追加,不与此行争位)。
